# Troubleshooting Notes

## Common Development Issues

### Servo Alignment
Issue:
- Uneven walking or unstable posture.

Resolution:
- Re-run servo calibration and verify neutral alignment.

---

### Voice Assistant Detection
Issue:
- Commands not recognized consistently.

Resolution:
- Verify microphone configuration and command formatting.

---

### Camera Detection
Issue:
- Camera stream fails to initialize.

Resolution:
- Confirm camera interface is enabled and properly connected.

---

### Remote Access
Issue:
- SSH or VNC connection problems.

Resolution:
- Verify Raspberry Pi network connectivity and remote access settings.

---

### AI Workflow Testing
Issue:
- AI responses not generating correctly.

Resolution:
- Verify local AI configuration files and Python dependencies.
